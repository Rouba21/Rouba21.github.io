## Publier sur GitHub Pages
1. Créer un dépôt public nommé `Rouba21.github.io`
2. Y déposer `index.html`, `rouba.jpg`, `rouba-face.jpg` (et ce README)
3. Settings → Pages → Source : branche `main`, dossier `/root`
4. Le site est en ligne sur https://rouba21.github.io en 1 à 2 minutes
